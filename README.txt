PUSHPRAJ PATIDAR — PORTFOLIO WEBSITE

How to open:
1. Extract this ZIP folder.
2. Open index.html in any modern browser.

Files:
- index.html: portfolio content and structure
- style.css: responsive styling
- assets/pushpraj-profile.jpg: profile photograph

The website uses Google Fonts when an internet connection is available. All core layout and content are local.
To update details, edit index.html. To change the photo, replace assets/pushpraj-profile.jpg using the same filename.
